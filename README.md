# Portefólio · Nouhaila Essalmi

Programadora OutSystems / Low-Code no Porto.
Site: https://nouhaila-eessalmi.github.io

## Ficheiros

| Ficheiro | Para que serve |
|---|---|
| `index.html` | Estrutura da página |
| `estilo.css` | Cores, letras e layout |
| `projetos.js` | **Os meus projetos, competências, experiência e formação** (é aqui que edito) |
| `script.js` | Código que desenha a página a partir de `projetos.js` |
| `imagens/` | Capturas de ecrã dos projetos (pasta criada ao carregar a primeira imagem) |

## Como juntar um projeto novo

1. Carregar a captura de ecrã para a pasta `imagens/` (Add file → Upload files).
2. Abrir `projetos.js`, clicar no lápis ✏️ e copiar um bloco `{ ... }` de projeto.
3. Colar depois do último bloco, com uma vírgula entre os dois, e mudar os textos.
4. Em `imagem:` escrever `'imagens/nome-da-imagem.png'`.
5. Clicar em **Commit changes**. O site atualiza-se em 1 a 2 minutos.
